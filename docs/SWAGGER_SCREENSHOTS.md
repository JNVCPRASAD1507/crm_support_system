# Swagger UI Screenshots

Run the backend first:

`uvicorn app.main:app --reload`

Then open `http://localhost:8000/docs`.

Capture the Swagger UI for these groups for the EOD submission:
1. Authentication
2. Customers
3. Categories
4. Tickets
5. Comments / Attachments
6. Notifications / SLA
7. Dashboard / Audit Logs

The generated FastAPI OpenAPI document automatically contains request/response schemas and endpoint descriptions.
